<CourseCallout title="Lab framing">
  The goal is to connect the retrieval layer to generation without losing evidence discipline. Your assistant should be
  judged on whether it retrieves the right source, uses it faithfully, cites it correctly, and exposes the cases where
  the system is not ready for production.
</CourseCallout>

## Goal

Build a small RAG assistant over a course document collection and evaluate whether it retrieves and answers correctly.

## Suggested corpus

Use 5–10 documents such as:

- course syllabus;
- module descriptions;
- assignment instructions;
- grading criteria;
- university AI policy;
- selected technical documentation pages.

## Tasks

1. Parse and clean the documents.
2. Split them using at least two chunking strategies.
3. Attach metadata to every chunk.
4. Embed and index the chunks.
5. Implement semantic retrieval.
6. Add metadata filtering.
7. Add a grounded prompt template.
8. Generate answers with citations.
9. Create 10 evaluation questions.
10. Compare retrieval quality between the two chunking strategies.

## Required output

Students should submit:

- a short architecture diagram;
- the chunking strategy used;
- the metadata schema;
- retrieval examples;
- generated answers with citations;
- evaluation table;
- reflection on failure modes.

## Evaluation table template

| Question | Expected source | Retrieved in top-5? | Answer correct? | Citation correct? | Notes |
|---|---|---:|---:|---:|---|
| Example question | syllabus#assessment | Yes | Yes | Yes | Good retrieval |
| Example question | module-05#chunking | No | No | No | Query rewrite needed |
