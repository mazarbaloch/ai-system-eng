# AI Systems Engineering: Design of LLM-Powered Applications

## Course Description
This course focuses on designing, building, and evaluating modern AI systems powered by large language models (LLMs). Students will learn prompt engineering, structured outputs, RAG, AI agents, orchestration, and production deployment.

---

## Learning Outcomes
- Design LLM-powered systems
- Build RAG and agent systems
- Engineer prompts and context
- Optimize cost, latency, and performance
- Deploy scalable AI applications
